Layer Lab

Every layer of the RevUC drive, pulled apart: the desktop side-scroll and the phone top-down street. Toggle layers, change their parallax, reorder them, drop in your own images, save each layer as a PNG, and see exactly where replacement artwork goes. It uses the same painting code as the real page, so the palette (logo teal and orange), ginkgos and the photo-based 1819 Hub are all here.

Layers (bottom of the list is drawn last, in front)

On the phone the camera moves down the street. “Zoom” is the parallax: ground is 1.00, and taller things are drawn bigger (1.07 rooftops, 1.12 trees, 1.2 towers), so they drift faster as you scroll.

It is drawn as a vertical strip across the screen that repeats downward. Use speed to make it drift faster or slower than the street.

Make your own layer in code

// 1. an offscreen strip: 2000 units wide, 180 tall (3 pixels per unit)
var s = mk(2000, 180), c = s.x;

// 2. paint with units. The ground line is y = 138, the road starts at y = 148
wall(c, 100, 138 - 70, 60, 70, '#1f5f78');                          // blue brick block
foliage(c, 40, 120, 50, 18, ['#5f8f3a', '#9ab23a'], ['#ffd27a']);   // bush + flowers
ginkgo(c, 200, 138, 60);                                            // yellow street tree
tier(c, 300, 138, 24, 60, '#245c74');  cap(c, 300, 78, 24, 14, '#245c74');   // tower + pointed top

// 3. draw the visible slice every frame (f = parallax speed)
ctx.drawImage(s.c, cam * f * 3, 0, viewW * 3, 540, 0, 0, viewW, 180);

Canvas shapes vs. image files

  • Loading. Painted-in-code layers need no download but take under a second to paint at startup. Image files need a download first, then decode quickly. Wide full-resolution strips can be a few MB each, so use WebP for skies and PNG or WebP for transparent layers.
  • Preloading. Yes: create an Image, set src, await img.decode(), then ctx.drawImage(img, …). Load every layer with Promise.all and show a loading screen until they finish.
  • Same drawing code. A loaded image works in the layer list exactly like a painted canvas, because both go through drawImage. That is how the upload buttons here, and IMAGES / IMAGES_PHONE in the real page, work.
  • Published pages can’t fetch remote images. Embed them as data: URLs inside the HTML (about 33% bigger, 16 MB file limit). On your own site, normal image files are the better route.
  • Quality. Painting layers in Procreate, Photoshop or Krita gives real brush texture. Code-made layers are better for tiny files and quick edits.
