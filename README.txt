RevUC cleaned project files

1. RevUC_site_clean.html
   Main site entry point. Keep it in the same folder as revuc.css and revuc.js.

2. revuc.css
   Combined stylesheet for the painted scene, signs, responsive layout, FAQ storefront, forms and font controls.

3. revuc.js
   Original painted-city renderer and interactions, followed by the newer FAQ, form and font-pairing features.
   The drawing engine is intentionally retained so the existing visual artwork and parallax remain unchanged.

4. LayerLab_updated.html
   Asset lab with the existing buildings/landmarks plus the new FAQ storefront, updated form panels and font-pairing specimen.
   Individual SVG downloads are available in the Elements and New website additions galleries.
   The ZIP export also includes the new SVG components.
