Every layer and every piece of the painted Cincinnati drive, pulled apart. Preview the parallax, then download any layer, building, landmark, tree or car as a PNG or as an editable SVG for Illustrator or Figma. All of it is painted by the same code as the website.

Phone, tablet, laptop: one set is enough

You don’t need separate art for phone, tablet and laptop. The site paints the city in units (180 tall) and scales it to each screen. Pick a device to see what changes:

The same on every screen

Buildings, landmarks, trees, cars, lamps, the sun, the bridge, and the sidewalk and road tiles.

Only their length changes

The sky, the far skyline, Union Terminal and the street are long strips. Wider screens see more city at once, so their strips are longer. If you want one set, export Wide: it is the longest. Landmarks painted into a strip (UC, the 1819 Hub, Fountain Square) only line up exactly on the device size the strip was made for.

Each layer as its own file

Shown for the device picked above. The checkerboard is transparency. Full-layer SVGs are large because every brush mark is a shape; they take a few seconds to draw.

Elements

Single pieces, each on a transparent background with the ground line on its bottom edge. Windows are shown lit, as they look at night on the site. People are the crisp shapes; the site softens them with a blur and makes them walk.

Website components

The HTML parts of the site as clean SVG at the sizes the site shows them, in its vintage Cincinnati sign style: the About us enamel skyline board, the Schedule script arrow with its marquee, the neon Sponsors banner, the Tracks motel marquee, the FAQ rooftop letters and the map, plus the sign parts, the hero with the three interest-form buttons, the header and burger menu, the on-screen controls and the pop-up sheets. Text stays editable: Caveat Brush and Yellowtail (both free on Google Fonts, included in the zip) and Arial. PNGs are exported at 2×.

Make your own layer in code

// 1. an offscreen strip: 2000 units wide, 180 tall (3 pixels per unit)
var s = mk(2000, 180), c = s.x;

// 2. paint with units. The ground line is y = 138, the road starts at y = 148
wall(c, 100, 138 - 70, 60, 70, '#1f5f78');                        // teal brick block
ginkgo(c, 60, 138, 56);                                           // yellow ginkgo tree
tier(c, 300, 138, 24, 60, '#245c74');                             // tower segment
cap(c, 300, 78, 24, 14, '#245c74');                               // pointed top

// 3. draw the visible slice every frame (f = parallax speed)
ctx.drawImage(s.c, cam * f * 3, 0, viewW * 3, 540, 0, 0, viewW, 180);
